# Albom

*Sole / Soul — travel barefoot, dream wide.*

Локальный фоторедактор для подготовки снимков к [Travel Globe](https://gregory-gittools.github.io/travel-globe/). Личный некоммерческий проект. Работает полностью в браузере — фото не покидают компьютер, нет рекламы, нет сбора данных, нет сервера с базой. Страница целиком сгенерирована ИИ-помощником Claude.

## Запуск

1. Установлен Python.
2. Двойной клик по `start.bat` — поднимет локальный сервер и откроет `http://localhost:8642`.
3. **Chrome или Edge** — используется File System Access API (не работает в Firefox/Safari).

## Возможности

- **Альбом в одном окне** — дерево папок слева, редактор по центру, лента миниатюр снизу или сбоку (перетаскиваемая, с адаптивной раскладкой в несколько колонок и настоящими пропорциями фото). Правки сохраняются на месте, оригиналы автоматически копируются в `[Originals]`.
- **Коррекция** — выравнивание горизонта (автоматически через OpenCV.js или вручную), поворот на 90°, зеркальный разворот, перспективная коррекция (правка схождения вертикалей), кадрирование с фиксированными пропорциями (9:16, 4:5, 1:1, 3:2, 16:9).
- **Цвет** — подбор цветокоррекции по вариантам (авто-контраст, ч/б и др.) с превью-сеткой; навигация по вариантам стрелками клавиатуры так же, как по ленте фото.
- **Параметры и карта** — панель EXIF-параметров (камера, объектив, дата и т.д.) с ручным редактированием; при наличии геометки — карта на месте съёмки (Leaflet) и открытие в отдельном окне.
- **Слайд-шоу** — показ отобранных фото на весь экран.
- **Пометки** — избранное (звёздочка), восстановление из `[Originals]`.
- Открытие папки в Проводнике Windows по клику в дереве — через маленький локальный `server.py` (File System Access API намеренно не отдаёт странице реальный путь к файлу).

## Ограничения

- Только Chrome/Edge (File System Access API).
- Одно окно браузера, без фоновой/пакетной обработки.
- Никакой синхронизации/облака — всё хранится и обрабатывается локально.

## Технологии

[OpenCV.js](https://docs.opencv.org/4.9.0/d5/d10/tutorial_js_root.html) (поиск линии горизонта), File System Access API, [Leaflet](https://leafletjs.com/) (карта), шрифт Poppins (Google Fonts).
