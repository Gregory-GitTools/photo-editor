# tool-photo-crop-9x16

Локальный инструмент для обрезки фото под формат 9:16 (весь экран смартфона) с ручной интерактивной рамкой, подсказками по горизонту/вертикалям и лёгким автоулучшением. Работает полностью локально — фото никуда не загружаются.

## Запуск

1. Установлен Python (для локального сервера).
2. Двойной клик по `start.bat` — откроется браузер на `http://localhost:8642`.
3. **Работает только в Chrome или Edge** (нужен File System Access API — в Firefox/Safari не поддерживается).

## Как пользоваться

1. «Выбрать папку с фото» — папка с исходными снимками.
2. «Выбрать/создать папку результата» — создаётся подпапка `9x16` внутри исходной (можно изменить имя в коде, `App.State.outputName`).
3. «Начать» — приложение находит необработанные фото (уже сохранённые в папке результата — пропускаются, можно прерывать и продолжать).
4. Для каждого фото:
   - Ползунок «Выровнять горизонт» — предложенный угол определяется автоматически (по линии горизонта), можно поправить вручную. Жёлтые линии — подсказки по вертикалям (стены зданий и т.п.), перспектива не выправляется — это просто ориентир.
   - Рамка 9:16 — тащить целиком (сдвиг) или за угол (изменение размера, противоположный угол — точка опоры).
   - «Сохранить и дальше» — применяет поворот, кроп и лёгкое автоулучшение (автоконтраст + насыщенность) к полноразмерному фото и сохраняет в папку результата с тем же именем файла.
   - «Пропустить» — перейти дальше без сохранения. «Назад» — вернуться к предыдущему фото. «Сбросить рамку» — вернуть рамку и угол к значениям по умолчанию для текущего фото.

## Ограничения

- Перспективная коррекция (схождение вертикалей) не делается — только подсказка линиями.
- Работает в одном окне браузера, без пакетной/фоновой обработки.
